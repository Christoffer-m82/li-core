    Conversation history

    Your private conversations remain until you delete them. Deletion also removes linked specialist history from active storage; encrypted provider backups age out under the documented schedule.

    Private files

    Saved uploads and Li-created files from governed storage. Li-created files expire unless you keep them.

    Settings

    Appearance

    Choose a look without changing Li’s content or permissions. Themes are saved on this device. Auto switches between Light and Dark.

    Transfer a Li appearance JSON file (16 KB maximum). Import opens a new draft for review, never replaces existing themes, and does not upload anything. Auto exports its currently displayed Light/Dark palette.

    Create another theme

    Start with Forest’s palette and adjust it. There is no fixed theme-count limit; browser storage capacity applies. Fonts use locally available families—no external font requests. Built-in themes cannot be overwritten.

    Install Li

    Install Li from this browser for a dedicated app window and quick access from your Android home screen or Windows Start menu.

    Voice & Privacy

    Voice starts only when you press the microphone and your browser grants permission. Audio is processed ephemerally by the browser speech capability and is not uploaded, logged, stored in memory, analytics, artifacts, or conversation history by Li. Only the visible transcript is handled like a normal chat message. Availability, quality, and language voices vary by browser and device.

    Data & Privacy

    Uploads are temporary unless you explicitly save them. Files Li creates are private and expire automatically. Specialist interactions contain only real orchestration events and remain until you delete them.
